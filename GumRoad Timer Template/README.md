# ⏳ Gumroad Timer Launch Template

A modern, elegant landing page template with a cinematic video background, animated countdown timer, social media icons, newsletter modal, and partnership notification.  
**Perfect for product launches, coming soon pages, or digital campaigns!**

---

## 🚀 Features

- 🎬 **Fullscreen video background** for a cinematic look
- ⏲️ **Live countdown timer** to your launch date (easy to customize)
- 🆔 **Animated title**: "WELCOME" shrinks and grows for a dynamic effect
- 🌐 **Social media icons** (Instagram, LinkedIn, WhatsApp, YouTube, Facebook, Newsletter)
- 📨 **Newsletter modal**: users can subscribe with their email
- 🤝 **Partner notification**: elegant popup inviting users to become your partner
- 🖋️ **Modern typography** (Bebas Neue Google Font)
- 🥚 **Console easter egg** for curious visitors
- 📱 **Responsive design** for all devices

---

## 📦 What’s Included

- `index.html` – Main HTML file (ready to upload to Gumroad or any static host)
- `style.css` – All styles (linked in HTML)
- `main.js` – All JavaScript logic (linked in HTML)
- `assets/` – Folder for your images, icons, and video background

---

## 🛠️ How To Use

1. **Unzip and upload all files** to Gumroad (or your preferred static hosting).
2. **Edit `index.html`** to change text, links, or add your logo.
3. **Replace images and video** in the `assets/` folder with your own.
4. **Set your launch date** in `main.js`:
   ```js
   const targetDate = new Date("May 24, 2027 00:00:00").getTime();
   ```
5. **Customize social links** in the HTML as needed.
6. **All styles and scripts are already linked!**

---

## 📝 Customization

- **Change the video background:**  
  Replace `assets/Video-Background.mp4` with your own video.
- **Change social icons:**  
  Replace images in `assets/` and update links in the HTML.
- **Newsletter:**  
  The newsletter modal is a demo (no backend).  
  To collect real emails, connect to a service like Mailchimp, Brevo, etc.
- **Partner notification:**  
  The "Become Partner" button opens an email to `srlbuga@gmail.com`.  
  Change this address if needed.

---

## 💡 Tips

- For best results, use high-quality images and a short, loopable video.
- All code is commented for easy editing.
- If you want to use only one file, you can inline the CSS and JS into `index.html`.
